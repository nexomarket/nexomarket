# NexoMarket — primera versión

Esta carpeta contiene una primera versión visual y responsive de NexoMarket.

## Archivos
- index.html — estructura de la web
- styles.css — diseño oscuro/minimalista
- script.js — catálogo y modal de compra de demostración

## Importante
El checkout actual es SOLO una demostración. Todavía no está conectado a PayPal ni a un procesador de tarjetas, y no envía PDFs.

2. Generar las portadas definitivas.

4. Crear backend/base de datos para registrar compras.
